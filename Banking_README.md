# Banking Management System - MySQL

A complete **Banking Management System** database project built using **MySQL 8.0+**. The project demonstrates relational database design, SQL querying, database programming, transactions, auditing, normalization, indexing, analytical queries, and reporting.

## Project Overview

The database manages key banking operations involving:

- Customers
- Branches
- Employees
- Accounts
- Transactions
- Beneficiaries
- Loans
- Loan Payments
- Cards
- Audit Logs


## How to Run

1. Install **MySQL Server 8.0+** and **MySQL Workbench**.
2. Open MySQL Workbench and connect to the MySQL server.
3. Open `banking_management.sql`.
4. Execute the script in order.
5. Run the final reports to verify the results.

> Some DCL operations such as `CREATE USER`, `GRANT`, and `REVOKE` require suitable administrator privileges.

## MySQL Safe Update Mode

If MySQL Workbench raises **Error 1175** for an intentional UPDATE or DELETE, Safe Update Mode can be disabled temporarily for the current session:

```sql
SET SQL_SAFE_UPDATES = 0;

-- required UPDATE or DELETE statement

SET SQL_SAFE_UPDATES = 1;
```

Verify the affected rows before executing destructive statements.
